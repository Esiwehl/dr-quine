# Dr_Quine

Dr_Quine is a project from the 42 curriculum that explores self-reproducing programs, commonly known as quines.
A quine is a program that outputs its own source code without reading that source from a file.
The project consists of three programs; Colleen, Grace, and Sully each implemented in both C and x86-64 assembly. Together, they explore different approaches to self-reproduction, from printing source code to generating and executing new versions of a program.

## Project Structure
```
Dr_Quine/
├── C/
│   ├── Colleen.c
│   ├── Grace.c
│   ├── Sully.c
│   └── Makefile
├── ASM/
│   ├── Colleen.s
│   ├── Grace.s
│   ├── Sully.s
│   └── Makefile
└── README.md
```

Each implementation has its own Makefile and produces three executables: Colleen, Grace, and Sully.

# Requirements
* The project targets Linux x86-64.
* To build and run both implementations, you will need:
* A C compiler, such as GCC or Clang
* NASM (for the assembly implementation)
* GNU Make
* A standard Linux development environment

## Building

The C and assembly implementations each have their own Makefile.
To build the assembly programs:
```bash
cd [desired implementation]
make
```

To build an individual program:

```bash
make Colleen
make Grace
make Sully
```

### Makefile Rules

| Command | Description |
|---|---|
| `make` / `make all` | Compiles all three programs. |
| `make Colleen` | Compiles Colleen. |
| `make Grace` | Compiles Grace. |
| `make Sully` | Compiles Sully. |
| `make clean` | Removes object files (`.o`). |
| `make fclean` | Removes object files and executables. |
| `make re` | Performs a complete rebuild. |
| `make cGrace` | Removes the `Grace_kid.s` file generated by Grace. |
| `make cSully` | Removes the source files, object files, and executables generated by Sully (`Sully_0` through `Sully_5`). |

### Generated File Cleanup

Grace and Sully generate additional files during execution. These are not removed by the standard `clean` and `fclean` rules.
Two additional targets are provided to clean up these files independently:

```bash
make cGrace
make cSully
```

This allows the generated files to be inspected and compared with the original source before deleting them.
